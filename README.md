# TLSR8208-Tutorial

公众号系列文章「TLSR8208 开发入门」（A00~A29）的配套代码。芯片是泰凌微 TLSR8208（SDK 里叫 B80），开发板 C1T261A30 V1.1（TLSR8208ADK56D，板上是 TLSR8208A + 外挂 512 KB Flash）。

## 基线

| SDK | 版本 | 工程 |
|---|---|---|
| Platform（驱动）SDK | tc_platform_sdk V3.5.1 | `project/tlsr_tc32/B80`，工程名 `B80_Driver_Demo` |
| BLE 单连接 SDK（2.4G 私有协议是同一个仓库） | tc_ble_simple_sdk V3.4.2.2 + patch_0001 | `b80_ble_sdk/project/tlsr_tc32/B80`，工程名 `tc_ble_simple_b80_sdk` |

工具链是 IoT Studio V2025.2 自带的 TC32 GCC（`tc32-elf-gcc --version` 输出 `4.5.1-tc32-1.3`）。SDK 和 IoT Studio 从泰凌官网下载。BLE SDK 的 patch_0001 没有打进源码，要按 SDK 里 `tc_ble_simple_v3.4.2.2_Patch/patch_0001_20251205/Patch_Guide.txt` 手动替换文件、删掉两个 `rf_private_pa` 文件（见第 5 篇）。

## 怎么用

1. 准备一份干净的 SDK。建议在 SDK 根目录 `git init` 提交一次，换例程时用 git 恢复原样。
2. 打开对应篇目的目录。每个子目录是一个固件：改过的源文件按 SDK 根目录下的相对路径摆放（Platform 是 `tc_platform_sdk-V3.5.1/`，BLE 是 `b80_ble_sdk/`），`改动.diff` 是相对官方 SDK 的差异，可以直接 `git apply`。
3. IoT Studio 导入 `project/tlsr_tc32/B80`，选篇目 README 里写的编译配置编译。

每个目录只放改动的文件，不含泰凌的完整 SDK。所有固件我都在自己电脑上按上面的基线重新编译过，0 errors、0 warnings。一共 51 个，和我当时编的 bin 对照：43 个 sha256 一致，3 个当时只记了大小、大小一致；第 17、18、29 篇各有一个不带日志的 `_nolog` 版本，大小和文章开头「验证状态」里写的一致（当时没留 bin）；第 13 篇是按正文重建的，第 20 篇的「自定义配对」当时只做了编译，这两个没有可比对的原件。目录里附的 `.bin` 就是这次编出来的，用 BDT 从 Flash 地址 0 下载。没有放 `.elf`、`.lst`，它们带着我电脑上的路径，需要的话自己编。

每篇做到哪一步（读源码、编译、上板看现象、仪器实测），以文章开头的「验证状态」为准。

**注意**：BLE SDK 的 `drivers/printf.h` 是全工程共用的。很多 BLE 固件打开了日志（PD3 输出，GPIO 模拟串口 115200），覆盖这个文件后其他配置也会带日志，正式固件记得改回去。
